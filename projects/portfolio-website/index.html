Introduction

This website is my personal portfolio and a place for me to show my projects, skills, experience, and interests all in one place. I built it by hand using HTML, CSS, and JavaScript rather than using a website builder or frontend framework.

The project originally started as a way for me to get more comfortable with web development, but it quickly became something actually useful to me. Since the website itself is what recruiters and other people use to learn about my work, I also had to think about how the information was organized and presented instead of just how the site looked.



Designing Around the User

The main audience for the site is someone who may only spend a minute or two looking thorugh it, so I wanted the important information to be easy to find without overwhelming the user.

I kept the navigation and overall design relatively simple and separated information into clear sections for projects, skills, my resume, product thinking, and information about me. I also worked on making the layout responsive so that the same content is usable on both desktop and mobile devices.

Building the site has been a useful reminder that adding more isn't always an improvement. A porfolio needs to communicate information quickly, so I've tried to prioritize readability and ease of navigation over adding features just to do it.



Building the Website

As the site grew, I started separating reusable parts such as the header, footer, and page metadata instead of copying the same HTML onto every page.

I also moved project information into JSON format and use JavaScript to generate project listings and some of the content on individual project pages. This makes adding and updating projects much easier than manually maintaining the same information in multiple places.

The site also gave me practical experience with responsive CSS, JavaScript, JSON, basic social sharing metadata, Git, and deploying a real website under my own domain.
